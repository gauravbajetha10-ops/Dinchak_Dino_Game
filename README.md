## 📖 Game Explanation
**Dinchak Dino Game** is an exciting, endless 2D side-scrolling survival game developed in Unity. 

In this fast-paced action game, players control a dynamic character trying to survive in a world filled with incoming monsters and obstacles. The core mechanic revolves around timing and precision—enemies spawn dynamically from the edges of the screen, and the player must react quickly to dodge and jump over them. 

### Key Features:
* **Endless Survival Action:** Enemies spawn dynamically using randomized timers and Coroutines, ensuring no two playthroughs are exactly the same.
* **Physics-Based Movement:** Smooth and responsive player movement using Unity's Rigidbody2D, customized gravity scales, and precise collision detection.
* **Character Selection:** A fully functional Main Menu allowing players to pick their favorite character before jumping into the action.
* **Persistent Game Management:** Utilizes the Singleton design pattern to seamlessly transfer selected character data between the UI menus and the core gameplay scene.

## 🎮 How to Play
The objective is simple: **Survive as long as possible!** 

**Controls:**
* **Move Left:** `A` Key or `Left Arrow`
* **Move Right:** `D` Key or `Right Arrow`
* **Jump:** `Spacebar`

**Rules:**
1. Navigate the level and avoid touching any of the incoming monsters.
2. Time your jumps perfectly to clear the enemies.
3. If an enemy touches you, it's **Game Over**.
4. Use the **Restart** button to immediately try again, or the **Home** button to return to the character selection screen.

## 🛠️ Installation & Setup (For Developers)
To explore the code or play the game directly in the Unity Editor:

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/gauravbajetha10-ops/Dinchak_Dino_Game.git
   ```
2. Open **Unity Hub** and click **Open**.
3. Select the cloned `Dinchak_Dino_Game` folder.
4. Navigate to the `Scenes` folder in the Project window.
5. Open the `MainMenu` scene and press the **Play** button at the top of the editor!
